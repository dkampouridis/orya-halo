# Data sources and licences

Orya Halo is non-commercial and display-only. Every source below was checked on
**2026-11-14** against the provider's own documentation and terms. The same facts live in code:
each plugin in `packages/sources` carries a `licence` and `attribution`, and the gateway
serves its upstreams' terms at `/v1/attribution`. If this page and the code disagree, fix both.

The rule: if a source forbids public display, we do not use it. If it forbids redistribution,
its data never passes through the gateway; the browser fetches it directly.

## Aircraft models

The 3D aircraft are generated in code from published dimensions (length, wingspan, fuselage
width, wing sweep, engine layout), which are facts rather than anyone's design. No third-party
3D model, livery artwork or logo is used, so there is nothing to license or credit.

They are painted in simplified airline colour schemes (`packages/schema/src/aircraft-liveries.ts`):
a few flat colours per airline (fuselage top and belly, fin, engines), chosen by eye as an
impression of how its aircraft look from a distance. No logo, name, emblem, typeface or artwork
is drawn, the schemes are not copies of any livery, and no airline made or endorsed them. The
airline is read from the flight's callsign; nothing else about the airline is shown.

## Share-alike

`apps/web/public/data/cables.bin` and the base map extract are databases derived from
OpenStreetMap, and aircraft positions relayed by the gateway derive from adsb.lol. All three
are offered under the [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/), not under
this repository's MIT licence, which covers the code only.

## Considered and not used

| Source                             | Why not                                                                                                                                                                       |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OpenSky Network                    | Research and non-commercial use only; its licence forbids making data available to third parties                                                                              |
| airplanes.live                     | Terms forbid public display and distribution without written permission                                                                                                       |
| adsb.fi                            | "Personal, non-commercial use only": unclear for a public site. Implemented in the gateway but off by default; enable it only for private use                                 |
| adsb.one                           | API repository archived, no terms                                                                                                                                             |
| ADSBHub, AISHub                    | Require running and sharing your own receiver; AISHub forbids passing on raw data                                                                                             |
| TeleGeography submarine cable data | The data is under a paid licence; only the map images are openly licensed                                                                                                     |
| Windy Webcams API                  | Terms forbid publishing the API key (a browser app would) and forbid redistribution (so no gateway proxy either). A plugin exists in `packages/sources` but is not registered |
| Caltrans CCTV                      | No clear licence; images "may require additional permissions"                                                                                                                 |
| NZTA traffic cameras               | No CORS, so not usable from a browser                                                                                                                                         |
| Kystverket (Norway) AIS            | Open licence (NLOD), but its endpoint was unreachable when tested. A good next keyless ship feed                                                                              |
| Launch Library 2                   | No licence or terms found for the free API                                                                                                                                    |
| TomTom / HERE traffic              | Optional in the original plan; not built                                                                                                                                      |

## Cameras

Only cameras that a public authority publishes as open data are included. Orya Halo never
indexes unsecured or private camera feeds.
